# O Gargalo Esquecido: Como a Vulnerabilidade 'Cordyceps' em CI/CD Expõe um Risco de US$ 10 Bilhões na Infraestrutura de IA

**Enquanto o mercado foca em modelos e chips, o elo mais fraco da cadeia de IA pode estar num pipeline de deploy mal configurado — e a pesquisa da Novee Security acaba de provar isso.**

## O Que Aconteceu

Em 24 de junho de 2026, a Novee Security divulgou uma pesquisa que identificou um padrão de vulnerabilidade batizado de "Cordyceps" — uma referência ao fungo que controla hospedeiros. A descoberta é simples e aterradora: uma fraqueza em pipelines de CI/CD (Integração Contínua e Entrega Contínua) que permite que **qualquer pessoa com acesso não autenticado** assuma o controle do pipeline de deploy de uma empresa.

O padrão Cordyceps não é uma falha de uma ferramenta específica. É um *design flaw* arquitetural que afeta dezenas de plataformas de CI/CD, desde soluções open source como Jenkins e GitLab Runner até serviços gerenciados como GitHub Actions e CircleCI. A pesquisa mostra como atacantes podem injetar código malicioso em artefatos de build que, uma vez implantados, comprometem toda a cadeia de suprimentos de software — incluindo modelos de IA, agentes e APIs.

A Novee Security demonstrou o ataque em ambientes controlados, conseguindo substituir modelos de machine learning em produção por versões backdooradas, sem que os sistemas de monitoramento detectassem a troca.

## A Análise Profunda

### O Mecanismo do Ataque

O padrão Cordyceps explora uma suposição fundamental dos pipelines modernos: **a confiança cega no artefato final**. O fluxo típico é:

1. Desenvolvedor faz commit → 2. CI/CD testa e builda → 3. Artefato é armazenado em registry → 4. Deploy automático

O que a Novee Security descobriu é que, em várias implementações, o **estágio de build não valida a integridade do artefato contra o repositório de origem**. Se um atacante consegue acesso ao registry de artefatos (muitas vezes exposto por falta de autenticação), ele pode substituir o artefato legítimo por um malicioso. O pipeline de deploy, confiando no artefato, implanta a versão comprometida.

O nome "Cordyceps" vem da capacidade do fungo de controlar o comportamento do hospedeiro sem destruí-lo imediatamente. No caso do CI/CD, o pipeline continua funcionando "normalmente", mas agora entregando software comprometido.

### Dados Quantitativos da Pesquisa

A Novee Security analisou **mais de 12.000 pipelines públicos** em empresas de tecnologia e encontrou que **aproximadamente 8%** apresentavam o padrão Cordyceps em algum grau. Destes:

- 62% usavam registries de artefatos sem autenticação
- 34% não tinham validação de checksum entre build e deploy
- 28% permitiam overwrite de artefatos sem versionamento

Entre as empresas afetadas, estavam **três dos cinco maiores provedores de nuvem** e **duas plataformas de deploy de modelos de IA** que, juntas, gerenciam mais de 200.000 modelos em produção.

## Impacto Real: Números e Mercado

### O Custo da Infraestrutura Comprometida

O mercado global de CI/CD foi avaliado em US$ 1,2 bilhão em 2025, com crescimento anual de 18%. Mas o custo real da vulnerabilidade está no que ela protege: **todo o ecossistema de software empresarial**.

Para o mercado de IA, o risco é particularmente agudo. Considere:

- **Modelos como artefatos**: Modelos de machine learning (arquivos .pkl, .h5, .pt) são tratados como artefatos de build. Um ataque Cordyceps pode substituir um modelo de detecção de fraudes por um que ignore transações suspeitas.
- **Agentes de IA**: Agentes autônomos dependem de pipelines de CI/CD para atualizações. Um agente comprometido pode executar ações maliciosas com credenciais legítimas.
- **APIs de inferência**: O deploy contínuo de APIs de IA significa que cada atualização é um vetor potencial de ataque.

Estimamos que **US$ 10 bilhões em infraestrutura de IA** estejam expostos a ataques do tipo Cordyceps, considerando o valor dos modelos, dados de treinamento e receita de inferência que poderiam ser comprometidos.

### O Efeito em Cadeia

O pior cenário não é o roubo de um modelo, mas a **contaminação silenciosa** de múltiplos sistemas. Um atacante que compromete o pipeline de CI/CD de uma plataforma de IA como serviço pode:

1. Injetar backdoors em dezenas de modelos simultaneamente
2. Coletar dados de entrada dos usuários (prompts, dados de negócio)
3. Manipular saídas para favorecer decisões específicas (fraude, desinformação)

A pesquisa da Novee Security mostrou que, em um cenário simulado, um ataque Cordyceps levou **17 dias para ser detectado** — tempo suficiente para extrair dados de 40.000 usuários e modificar 1.200 modelos.

## O Que Fazer Com Isso

### Para Desenvolvedores e DevOps

1. **Valide artefatos em cada estágio**: Implemente verificação de checksum entre o build e o deploy. Use assinaturas digitais em artefatos de modelo.
2. **Imutabilidade de registries**: Configure registries de artefatos para modo append-only, impedindo overwrite de versões existentes.
3. **Autenticação em todos os endpoints**: Qualquer registry exposto sem autenticação é um convite ao ataque. Use tokens de curta duração.

### Para Gestores de Infraestrutura de IA

1. **Audite seus pipelines**: A Novee Security liberou um script de verificação para o padrão Cordyceps. Execute-o em todos os pipelines que deployam modelos.
2. **Separe ambientes de build e deploy**: O pipeline que builda o modelo não deve ter acesso direto ao ambiente de produção. Use approvals manuais para deploys críticos.
3. **Monitore a integridade dos modelos**: Implemente monitoramento contínuo que compare o hash do modelo em produção com o hash esperado.

### Para Investidores e Líderes de Tech

1. **Due diligence em segurança de CI/CD**: Ao avaliar startups de IA, pergunte sobre a segurança do pipeline de deploy. Empresas que tratam CI/CD como "só mais uma ferramenta" são alvos fáceis.
2. **Cobertura de seguro cibernético**: Verifique se sua apólice cobre ataques à cadeia de suprimentos de software. Muitas seguradoras ainda não consideram esse vetor.
3. **Padrão de indústria**: Apoie a criação de um padrão de segurança para pipelines de IA, similar ao que o OWASP faz para aplicações web.

## O Que Monitorar

1. **Resposta dos provedores de CI/CD**: GitHub, GitLab, CircleCI e Jenkins devem lançar patches ou configurações recomendadas para mitigar o Cordyceps. Acompanhe os comunicados oficiais.
2. **Ferramentas de verificação**: A Novee Security prometeu lançar uma ferramenta open source de detecção. Fique atento ao repositório deles.
3. **Casos reais**: Se o padrão Cordyceps é tão comum quanto a pesquisa sugere, é questão de tempo até vermos o primeiro ataque de grande escala. Monitore o CVE database e feeds de segurança.
4. **Regulamentação**: A vulnerabilidade pode acelerar discussões sobre certificação de segurança para plataformas de IA, especialmente na Europa com o AI Act.
